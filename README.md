# Video Game Sales Analysis — Power BI

## Project Overview
An interactive Power BI dashboard built to analyze video game sales across regions, genres, platforms, and release years. The project explores sales trends and helps users compare market performance using interactive filters.

## Business Questions
- How have video game sales changed over time?
- Which regions contribute to the most sales?
- Which platforms generate the highest sales?
- Which genres have the highest total and average sales?
- How does year-over-year sales growth vary across markets?

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for measures and calculations
- GitHub for project versioning and portfolio presentation

## Dashboard Features
- **KPIs:** Global Sales, Unique Games, Average Sales per Game, and Year-over-Year Growth.
- **Global Sales Trend:** Historical sales trends over time.
- **Regional Sales Composition:** Comparison of sales across North America, Europe, Japan, and Other regions.
- **Top Platforms:** Dynamic platform rankings.
- **Genre Analysis:** Comparison of total sales and average sales per game.
- **Interactive slicers:** Explore results by year and market.

## Data Preparation & Analysis
- Prepared the dataset using Power Query.
- Excluded records with missing release years from the year-based analysis.
- Created DAX measures for sales, distinct game titles, averages, and year-over-year growth.
- Implemented interactive market selection to compare regional performance.

## Repository Contents
- `Video_Game_Sales_Analysis.pbix` — Power BI report and data model.

## How to Explore
Download the `.pbix` file and open it using Power BI Desktop to interact with the dashboard.

## Notes
Sales figures are expressed in millions of units. The dataset contains historical video game sales records, and missing or incomplete years should be considered when interpreting trends.
